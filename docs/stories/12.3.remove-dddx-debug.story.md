# 12.3: Rimozione `dddx()` dal codice di produzione

**Story ID:** 12.3  
**Epic:** 12 — Audit UI/Filament modulo User  
**Slug:** remove-dddx-debug  
**Status:** backlog

## Story

Come **utente del panel**,
voglio **non incappare mai in un dump di debug (dd/dddx) navigando il panel**,
così che **la UI non si blocchi mai per un residuo di sviluppo**.

## Evidenza (grep `dddx(` 2026-09-22)

UI:
- `app/Filament/Pages/Password.php:92`
- `app/Filament/Clusters/Appearance/Pages/Favicon.php:65,69`
- `app/Filament/Clusters/Appearance/Pages/Background.php:73,77`
- `app/Filament/Clusters/Appearance/Pages/CustomCss.php:65,69`

Fuori scope UI (segnalazione): `app/Models/BaseProfile.php`, `app/Models/BaseUser.php`.

## Acceptance Criteria

1. Grep `dddx(` in `app/Filament` → zero hit.
2. I `dddx` erano **dead code** accanto alla chiamata utile: rimuovere solo il debug, la logica (salvataggio, validazione, redirect) resta identica.
3. Nessuna modifica di comportamento osservabile (nessuna migrazione, nessuna route).
4. `app/Http/Livewire/TermsOfService.php` NON viene corretto: resta in carico a 10.4 (ritiro).
5. PHPStan `Modules/User` level max pulito dopo la rimozione.
